River Conditions: design reference

Visual spec for the river-conditions/gauge block and [river_conditions] shortcode. The CSS at the top of this file is the reference stylesheet; everything below "Reference page chrome" is presentation only. All numbers are sample data. Fonts inherit from the theme.

1 · Card: ok (default)

Big number = latest 00060. Trend = latest vs ~6h ago (±5%). Sparkline = 7-day 00060, server-rendered SVG. "Live" tag only when data < 3h old.

2 · Card: gauge without temperature

Missing parameters are hidden entirely, never "0" or "—". Stats grid reflows.

3 · Card: stale (last known good)

Triggered when the newest 00060 reading is older than 3h, or when the API fails and the 48h last-known-good cache is served. No trend chip or sparkline when stale.

4 · Card: unavailable (no data, no cache)

Invalid site IDs render nothing publicly (HTML comment only). Editors see an inline notice in the editor.

5 · Compact layout, inline in an article

…the Madison fishes best on the swing this time of year. Check flows before you go:

If it’s rising fast after rain, expect off-color water and fish the edges.

6 · Theming via CSS custom properties

A theme only overrides --rivcon-* variables. Shown: a dark theme. No plugin CSS changes needed.
